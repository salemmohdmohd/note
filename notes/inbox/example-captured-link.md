# Example Captured Link

This is what a saved article tends to look like: the link, a line about why it
seemed worth keeping, and space for notes once you have read it.

Source: <https://commonmark.org/help/>

## Why I saved it

A short reason, written while it is still fresh. Future you will not remember.

## Notes

Fill this in while reading. Then move the file to `notes/reading/` if it turns
into something you are actively working through, or to `notes/archive/` when you
are finished with it.

Moving a note is just moving a file:

```bash
git mv notes/inbox/example-captured-link.md notes/archive/
```
